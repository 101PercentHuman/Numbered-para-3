# Numbered para 3

A custom Wikisource template for displaying numbered paragraphs, with the paragraph number positioned in the left margin and the paragraph text remaining in the normal text flow.

Based on [Template:Pline](https://en.wikisource.org/wiki/Template:Pline), which is designed for line numbering in poetry and plays. This template extends that approach with additional customisation options.

## Features

- Paragraph numbers positioned in the left margin.
- Anchor IDs for linking directly to individual paragraphs, with anchor highlighting.
- Customisable punctuation, font size, margin, colour, font style, and font weight.
- Support for additional CSS classes.
- Configurable anchor IDs, with automatic IDs generated by default.

## Repository contents

- `Numbered para 3.wiki` — Template Wikitext.
- `styles.css` — Template stylesheet.
- `doc.wiki` — Template documentation.

## Usage

```wikitext
{{Numbered para 3|1}}
```

Customised example:

```wikitext
{{Numbered para 3|4|size=100%|color=black}}
```

See the [live template](https://en.wikisource.org/wiki/Template:Numbered_para_3) for full documentation and examples.
